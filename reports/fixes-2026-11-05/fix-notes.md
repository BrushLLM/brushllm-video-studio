**BrushLLM Video Studio：第一轮修复记录**

日期：2026-11-05。针对此前评估中已复现的功能问题实施修复，并完成相关界面、队列与资源控制调整。

| 项目 | 已实现行为 |
| --- | --- |
| 默认音频转换 | 沿用源采样率/声道时不发送零值覆盖；六种目标格式默认参数可通过校验 |
| WebM + AV1 | 计划与命令共享容器编码规则，真实输出为 AV1；新增实际视频编码核验 |
| 旧编码字幕 | 烧录/封装页面提供源编码选项，并将选择传入任务；GBK 实际封装回归通过 |
| 输出预估 | 编辑操作显示实际输出容器；自动合并使用完整流兼容性判断；修正音频容器和编码显示 |
| 音频处理格式 | AAC、Vorbis、PCM 的处理格式与预留扩展名保持一致，避免保留格式与实际输出冲突 |
| GPU 压缩 | 自动码率结合源视频码率；显式目标码率保持用户选择；提供可能增大的预估提示 |
| 输出目录 | 展示完整有效目录；可选择源目录或恢复默认；IPC 明确区分继承设置与显式源目录 |
| 配置与提交 | 跨页面保存工具、参数、副输入、源编码和输出目录；准备任务时禁止重复点击并显示状态 |
| 文件探测 | IPC 探测并发上限设为 4；探测失败的文件可点击重试 |
| CPU 采样 | 使用异步子进程采样，避免同步采样阻塞主进程；同一任务不重叠采样 |
| 队列事件 | 由 App 统一订阅任务事件，移除队列页的重复订阅 |
| 文档和语言 | 工具数量更正为 26；新控件与提示覆盖九种语言 |

验证结果：266/266 测试通过，无跳过；生产构建通过；Electron 真实 IPC→队列→FFmpeg 冒烟测试通过，包含全局输出目录与显式源目录；浏览器预览完成默认音频提交、队列更新、跨页配置保留、目录显示和字幕编码入口检查。浏览器界面证据使用模拟媒体数据，实际编码和字幕处理另有真实 FFmpeg 回归。

低码率样例（640×360、6 秒）对照：输入 501,857 字节；修复前默认 GPU 压缩结果 936,972 字节；修复后结果 423,366 字节，比输入缩小约 15.6%。这只证明该回归样例得到改善，不能保证所有输入都变小；保留明确的体积提示。

低码率压缩样例的原始数据见 [compression-results.jsonl](compression-results.jsonl)。评估发现见[初始评估](../evaluation-2026-11-05/assessment.md)。

后续独立改进项仍包括轻量画面预览、重启后的任务恢复、探测缓存与大队列虚拟列表。本轮没有重构为完整视频编辑器，也没有完成 Windows 实机、4K/HDR 和长片压力测试。Windows CPU 采样等平台路径仍应在 Windows 环境验收。本轮修复已随 [v0.0.8](../../docs/releases/v0.0.8.md) 发布。
