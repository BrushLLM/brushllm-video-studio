## 修复与改进

- 修复音频格式转换默认采样率和声道导致无法加入队列的问题。
- 修复选择 WebM + AV1 时实际输出 VP9 的问题，并验证输出视频编码。
- 为字幕烧录和封装增加源编码选择，支持直接处理 GBK 等旧编码字幕。
- 修正输出容器、音频格式、自动合并及输出体积预估，显示实际输出目录。
- GPU 压缩自动码率参考源视频码率，降低低码率素材压缩后变大的可能，并增加体积提示。
- 切换页面保留工具参数，增加提交防重复、文件探测重试和并发限制。
- CPU 占用采样改为异步，减少主进程阻塞；移除队列重复事件订阅。
- 更新 macOS 安装窗口设计及九种语言文案。

发布前验证：266 项自动化测试通过，生产构建和 macOS Electron 真实媒体处理冒烟测试通过。

## Fixes and improvements

- Fixed default audio conversion settings preventing jobs from being submitted.
- Preserved AV1 when converting to WebM and added output codec verification.
- Added source encoding selection for subtitle embedding and burning, including GBK subtitles.
- Aligned output plans with actual containers, audio formats, merge decisions and output folders.
- Made automatic GPU compression bitrate aware of the source and added file size guidance.
- Preserved tool settings across pages; added duplicate submission protection, probe retry and bounded probe concurrency.
- Made CPU sampling asynchronous and removed duplicate queue event subscriptions.
- Refreshed the macOS installer layout and localized new controls in all nine languages.

Validation before release: 266 automated tests, production build and a macOS Electron smoke test with real media processing passed.
