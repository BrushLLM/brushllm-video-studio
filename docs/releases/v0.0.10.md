## What's new

- Browse video, audio, and subtitle tools from the left sidebar. Parameters stay on the left, with the media preview and processing queue on the right.
- Collapse the sidebar for a narrow window, or use the window toolbar to move back and forward.
- Settings use two columns in wider windows. System Language follows the operating system's preferred language.
- Advanced Mode, preset names, and other short control labels stay on one line when space allows.
- The macOS disk image uses the standard drag-to-Applications layout.
