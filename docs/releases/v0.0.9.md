## What's new

- Tools and parameters stay visible next to the source preview or live processing queue. Load a single preview frame on demand.
- Video Studio uses a dedicated teal and copper clapperboard icon in the app and installers.
- The queue shows progress, cancellation, errors and actual outputs. Audio tools share encoding settings, and subtitle batches keep processing other files after an individual failure.
- The nine README languages now share the same installation guidance and screenshots from the desktop app.
- The macOS package now bundles the GPL builds of FFmpeg and FFprobe. It supports Apple Silicon on macOS 12 or later.
